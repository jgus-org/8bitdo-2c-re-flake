Only the three `dumps/` files are committed; the firmware, the toolchain and the Ghidra module are fetched when a derivation is built, so evaluating or promoting this repository conveys nothing. Serving a built output does: `fw-*`, `payload-*` and `mod-*` put vendor code (a derivative of it, for `mod-*`) into the store, `tc32-tools` and `ghidra-tc32` put the toolchain binaries and the module there, and `nixosModules.xpad-2c-charge` conveys the patch, whose GPL-2.0-only corresponding source goes with it.
